## Phase 2: Visual & Design Excellence

### 2.1 Remove AI-Generated Aesthetic

**Current Issues to Address:**
- Generic gradient backgrounds
- Overuse of animation that feels template-based
- Stock photo aesthetic
- Predictable section layouts
- Default icon sets

**Premium Design Principles:**

**Color Psychology for HNWI:**
```
Primary Palette:
- Navy Blue (#0A1628) - Trust, stability, corporate credibility
- Gold Accent (#C9A962) - Wealth, exclusivity, premium positioning
- Charcoal (#2D3748) - Sophistication, modern executive
- Crisp White (#FFFFFF) - Clarity, transparency, minimalism

Avoid:
- Bright, saturated colors (appear unprofessional)
- Purple/cyan tech gradients (AI-generated look)
- Multiple competing accent colors
```

**Typography System:**
```
Headlines: Inter or Helvetica Neue (clean, authoritative)
Body: Georgia or Charter (readable, trustworthy)
Data/Metrics: IBM Plex Mono (technical credibility)
Accent: Playfair Display (sophisticated elegance)

Size Hierarchy:
H1: 48-64px (commanding presence)
H2: 32-40px (section authority)
Body: 18-20px (comfortable reading)
Captions: 14-16px (supporting details)
```

**Layout Architecture:**
- **Asymmetric Grids**: Break away from centered layouts
- **White Space Mastery**: Minimum 120px between major sections
- **Content Blocks**: Max 680px width for optimal readability
- **Visual Anchors**: Strategic use of dividers, not decorative elements

### 2.2 Premium Interaction Design

**Micro-interactions:**
- Subtle hover states (5-10% brightness change, not dramatic transforms)
- Smooth scroll with momentum (not jumpy anchor links)
- Cursor changes that indicate functionality (not cute custom cursors)
- Loading states that show progress (not generic spinners)

**Animation Principles:**
- Maximum 300ms transitions (faster feels responsive)
- Easing functions: cubic-bezier(0.4, 0, 0.2, 1) - natural acceleration
- Parallax: Subtle (0.1-0.2 factor), not nauseating
- Entrance animations: Once per session, not on every scroll

**Remove Immediately:**
- Typing animations (screams AI/template)
- Card flip animations (overused)
- Floating elements without purpose
- Particle effects / constellation backgrounds
- Rainbow gradient text
- Glowing buttons

### 2.3 Professional Photography & Videography

**Required Assets:**

1. **Executive Portrait**
   - Professional photographer (not selfie, not AI-generated)
   - Business formal or smart casual
   - Neutral background or office environment
   - High resolution (min 2000px width)
   - Multiple poses for different contexts

2. **Environmental Shots**
   - Working at desk with multiple monitors (shows technical depth)
   - Whiteboard strategy session (shows leadership)
   - Speaking/presenting (shows thought leadership)
   - Candid team collaboration (shows people skills)

3. **Process Documentation**
   - Screenshots of actual systems built (redact sensitive data)
   - Workflow diagrams (custom-created, not template icons)
   - Architecture diagrams showing technical sophistication
   - Data visualizations from real projects
